# Verified bibliography: research brief §2–§3 and paper draft

- **Scope.** Every work cited in `docs/research_brief.md` §2 (tables 2.1–2.7 and the lists in 2.6 and 2.8) and §3, plus `paper/references.bib` and the works named in `paper/sections/*.tex`.
- **Verification date.** 2026-11-18 (UTC). All primary pages were fetched on that day. The brief's own access date (2026-11-13) is kept in the brief. The task text asked for notes reading "verified 2026-11-13". They read 2026-11-18 instead, because that is when this check was actually run.
- **Companion file.** `verified_bibliography.bib`: 181 entries (156 arXiv works, 25 non-arXiv works). It contains only works whose metadata was taken from a primary page. It compiles with biblatex/biber with no warnings (test run in a scratch directory).
- **Method.**
  - arXiv: each abstract page was curled. Title, authors and first-version date come from its `citation_title`, `citation_author` and `citation_date` metas. All versions come from the submission history. Comments and journal-ref come from the metadata table. Where the brief makes a version-specific claim, the version page (`abs/<id>v1`) was also fetched.
  - Hugging Face: the datasets API, plus the card README where needed.
  - GitHub: the repositories were checked with `git ls-remote`, raw files (LICENSE, README, CITATION.cff, pyproject) and two blobless clones for commit dates. The GitHub web and API pages returned 403 in this environment.
  - Zenodo and Crossref: their APIs.
  - Blogs, ICML/ICLR and COLM: the pages themselves.
  - Downloads are stored, untrusted and uncommitted, under `/home/user/tc_review_dl/citation_verifier/`.
- **Keys.** Each key is the lowercase ASCII first-author surname (or the organisation or HF user), then the year of the first version (or of creation or publication), then the first title word. Leading "a", "an" and "the" are skipped and non-alphanumerics are removed (example: `wu2026swetogether`). The brief's own key for each work is shown in the status column as "brief ref …".
- **Columns.** "First version date" is arXiv v1 (`citation_date`, which equals the v1 date for all 156 works), with the latest version in brackets. For other works it is the creation or publication date that the primary page states. "Venue claim" quotes the arXiv comment or journal-ref verbatim when it names a venue or status. It also names any independent confirmation found (COLM 2026 list, ICLR 2026 page, Crossref). "none stated on arXiv" means the abstract page states no venue.
