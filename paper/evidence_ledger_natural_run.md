Every number in `paper/generated/natural_run/*.tex` (the tables and the number macros of `numbers.tex`, used in the text as `\nrv{key}`), with the file and fields it is read from. Generated by `python paper/make_tables.py --natural-run results/runs/natural-pr-v1`; nothing is entered by hand. A table cell's entry is `<row> | <family> = <cell>`; a caption's is `caption | <what> = <value>`. Each entry names the fields of its file as `<dot path>=<JSON value>`, and `absent` for a field the analysis does not hold. Every field belongs to one family, or to the run (its id, its families, the families of its second labeling, the size rule; its manifest's times, code revision, repeats, pilot flag and invocations, and the harness versions of its results): the run is in case-study mode (protocol §19.6, §20.3), so nothing is pooled over the families. The labels are D19's model proposals, the independent labeler's verdicts and the source-evidence labels; no human labels exist.
