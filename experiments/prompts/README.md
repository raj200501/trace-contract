# Prompts of the model-generated artifacts

* `workflows/`: the script of every workflow run (`tracecontract-brief-verification`, `tracecontract-final-audit`, `tracecontract-fix-verification`, `tracecontract-generate`, `tracecontract-heldout`, `tracecontract-internal-review`, `tracecontract-research-sweep`, `tracecontract-review-dispositions`, `tracecontract-round3-verification`, `tracecontract-text-corrections`), redacted as described below. Agent prompts are built from the templates in each script. Each header gives the run's start and finish time and status, the hash of the export and, where no owner-specific rule applied, the hash of the original script. Not exported: `tracecontract-privacy-fixes` (its prompts concern the repository owner's personal information). Its changes are in the git history and summarised in `docs/internal_review.md`.
* `agent_prompts.jsonl`: the prompt of every standalone agent (e.g. controlled-session agents, held-out generators for CS-03/CS-04, reference-check writers, mappers), with the time of its first and last transcript entry and the sha256 of the original prompt and transcript. A `note` marks agents whose output was not used.

Redacted before export: notes about the repository owner's messages, personal information (using owner-specific rules kept outside the repository), session ids, session-local paths and e-mail addresses. Where a note about the owner's messages or personal information was removed, the hash of the original is withheld (`prompt_sha256` is null; workflow headers say "withheld"), because it would let anyone confirm a guess of the removed wording. Exports pushed before 2026-11-18 (decision log D46) published those hashes. Workflow-run ids (`wf_...`) and agent ids are opaque harness identifiers; they are kept as provenance keys, for example in `tasks/*/labels/construction_checks.json` (`source`). The full transcripts are kept outside the repository (they contain harness internals); their hashes are recorded here and in `tasks/*/labels/generator_audit.json`.
