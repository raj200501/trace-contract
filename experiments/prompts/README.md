# Prompts of the model-generated artifacts

* `workflows/`: the exact script of every workflow run (contract recovery, verifier generation and audits, held-out generation and checks, brief verification, internal review). Agent prompts are built from the templates in each script. Not exported: `tracecontract-privacy-fixes` (its prompts concern the repository owner's personal information). Its changes are in the git history and summarised in `docs/internal_review.md`.
* `agent_prompts.jsonl`: the prompt of every standalone agent (e.g. controlled-session agents, held-out generators for CS-03/CS-04, reference-check writers, mappers), with the sha256 of the original prompt and transcript.

Redacted before export: notes about the repository owner's messages and personal information (using owner-specific rules kept outside the repository), session ids, session-local paths and e-mail addresses. Where an owner-specific rule changed a prompt, the hash of the original is withheld (`prompt_sha256` is null; workflow headers say "withheld"), because it would let anyone confirm a guess of the removed wording. Workflow-run ids (`wf_...`) and agent ids are opaque harness identifiers; they are kept as provenance keys, for example in `tasks/*/labels/construction_checks.json` (`source`). The full transcripts are kept outside the repository (they contain harness internals); their hashes are recorded here and in `tasks/*/labels/generator_audit.json`.
